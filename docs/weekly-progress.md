# Progres Mingguan

Catatan ringkas perkembangan proyek `myportofolio_mobile` per tutorial.

## Tutorial 08 — Aplikasi Portofolio Dasar

- Membuat proyek Flutter dan konfigurasi platform.
- Menyusun `MyHomePage` dengan tiga `InfoCard` dan tiga `ItemCard`.
- Menampilkan `SnackBar` saat kartu aksi ditekan.

## Tutorial 09 — Navigasi dan Form Proyek

- Memisahkan halaman ke `lib/screens/` dan widget bersama ke `lib/widgets/`.
- Menambahkan `LeftDrawer`, `ProjectFormPage`, dan navigasi `Navigator.push`.
- Menambahkan validasi dasar dan `AlertDialog` ringkasan proyek.
- Menambahkan widget test serta dokumentasi repositori.

## Tutorial 10 — Form Pendidikan

- Menambahkan `EducationFormPage` dengan input teks, dropdown, dan `showDatePicker`.
- Memusatkan validasi wajib isi, batas panjang, dan format URL di
  `lib/utils/validators.dart`.
- Memvalidasi urutan tanggal mulai dan tanggal selesai.
- Menambahkan kartu **Tambah Pendidikan** dan opsi **Add Education** di drawer.
- Membuat halaman utama dan form dapat digulir agar aman pada layar sempit.
- Menambah widget test untuk akses form, validasi, dialog ringkasan, dan alur Home.
- Memperbarui README dengan jawaban reflektif tambahan dan keterangan penggunaan AI.
